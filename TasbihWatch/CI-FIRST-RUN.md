## ① أنشئ المستودع (٣ دقائق)

1. اذهب إلى [github.com/new](https://github.com/new)
2. الاسم: `tasbih-watch` · النوع: **Public** ← (مهم: السيرفرات المجانية غير محدودة في المستودعات العامة)
3. لا تُضِف README ولا .gitignore (عندنا `.gitignore` جاهز) → **Create repository**

## ② ارفع الشيفرة (نسخ ولصق)

نفّذ هذه الأوامر في مجلد المشروع `TasbihWatch` (الذي نزّلته من مساحة العمل):

```bash
cd TasbihWatch

git init
git add .
git commit -m "سبحة: أول نسخة (تطبيق ساعة + ودجت + محاكي + اختبارات)"

# ← ضع معرّفك بدل USERNAME واسم المستودع بدل REPO
git remote add origin https://github.com/USERNAME/tasbih-watch.git
git branch -M main
git push -u origin main
```

> `.gitignore` جاهز ويمنع رفع `node_modules` ومشروع Xcode المُولَّد والمفاتيح الخاصة.

## ③ شاهد التشغيل

- افتح مستودعك ← تبويب **Actions**
- سترى **«✅ فحص الترجمة (بلا أسرار)»** يعمل تلقائيًا بعد الدفع
  (أو: **Actions ← فحص الترجمة ← Run workflow**)
- ستُبنى **٣ مهمات**:

| المهمة | ماذا تُثبت |
|---|---|
| 🔍 فحوصات الملفات | الاختبارات السريعة (jsdom) + فحص واجهات Swift — على سيرفر لينكس، ثوانٍ |
| 🛠️ ترجمة تطبيق الساعة (مستقل) | هل يُترجم التطبيق والودجت لـ watchOS؟ |
| 🛠️ ترجمة حاوية iOS + تطبيق الساعة داخل الحاوية | هل يترجم مسار النشر في TestFlight؟ |

## ④ النتيجة

- ✅ **BUILD SUCCEEDED** في الاثنين → الشيفرة سليمة، ننتقل لمسار النشر (BUILD-WITHOUT-XCODE.md)
- ❌ **BUILD FAILED** → افتح المهمة الفاشلة ← خطوة **«🛠️ ترجمة بلا توقيع»** ← ستجد الأخطاء في نهاية السجل
  بصيغة `error: …`، وملخّصها في خطوة **«📋 ملخّص النتيجة»**.

> 📌 **أرسل لي نص الأخطاء فقط** (سطور `error:`) وأصلحها فورًا وأدفع التصحيح — لا تحتاج Mac ولا معرفة Swift.

## الأسرار (لاحقًا فقط، عندما نصل للنشر)

سير العمل الثاني `build.yml` (أرشفة → رفع TestFlight) يحتاج **٤ أسرار فقط**
(**Settings ← Secrets and variables ← Actions ← New repository secret**):

| السر | من أين | مطلوب؟ |
|---|---|---|
| `APPLE_TEAM_ID` | developer.apple.com ← Membership ← Team ID (فيه ١٠ أحرف/أرقام) | ✅ |
| `ASC_KEY_ID` | App Store Connect ← Users and Access ← Integrations ← مفتاح API | ✅ |
| `ASC_ISSUER_ID` | نفس الصفحة (Issuer ID) | ✅ |
| `ASC_KEY_CONTENT` | محتوى ملف `AuthKey_XXXX.p8` كـ base64 | ✅ |
| `DIST_CERT_P12_BASE64` | شهادة `.p12` — **احتياطي فقط إن فشل التوقيع السحابي** | ⭕ اختياري |
| `DIST_CERT_PASSWORD` | كلمة سر ملف الـ p12 | ⭕ اختياري |

> 🎉 **لن تحتاج ماك ولا ملف شهادة يدوي**: مفتاح API وحده يكفي ليقوم سيرفر البناء
> (macOS مجاني) بإنشاء الشهادة والملفات التعريفية تلقائيًا (“التوقيع السحابي”).
> إن فشل ذلك، نضيف السرّين الاحتياطيين ونحلّها.

⚠️ **لا نضع هذه الأسرار الآن** — التشغيل الأول لا يحتاجها إطلاقًا.

## لماذا قد يفشل التشغيل الأول؟ (وما فعلته لمنع ذلك)

| السبب الشائع | الحالة عندنا |
|---|---|
| `-destination` بقيمة فارغة (متغيّر بيئة غير معرّف) | كان موجودًا فعلًا — **أُصلح** (`BUILD_DESTINATION: generic/platform=watchOS`) |
| نداء دالة محذوفة في الودجت | **أُصلح** قبل الدفع (فحص ① آلي) |
| اسم خاصية مكتوب خطأ في الواجهة (`model.x`) | **فحص ④ آلي جديد** يقارن كل مرجع بعضويات النموذج |
| صلاحية App Group ناقصة | **فحص ⑤ آلي** |
| عدم تطابق نصوص الأذكار بين التطبيق والمحاكي | **فحص ③ آلي** |
| مخطط (scheme) غير مشارَك فلا يراه `xcodebuild` | مُعرَّف صراحةً في المخطّطين |
| نوع معزول على MainActor يُستدعى من سياق خاطئ | أُعيد تصميم `MotionCounter` ليكون غير معزول + `CountingMode` خارج الصنف |
| مُحمّل SwiftUI غير متوافق مع watchOS | استُبدل `digitalCrownRotation` بالمُحمّل الأبسط + `onChange` |
| اسم أثر مكرر في `upload-artifact` (مدخلان من المصفوفة بنفس الاسم) | **أُصلح** — مفتاح فريد لكل مدخل (`standalone` · `container-ios` · `container-watch`) |
| مفتاح ناقص في أحد مداخل المصفوفة ⇒ اسم ملف/أثر فارغ | **فحص آلي جديد** يتحقق من كل مفتاح في كل مدخل على حدة |

**شغّل الفحوصات محليًا قبل الدفع (بدون إنترنت ولا Mac):**

```bash
cd tests
python3 workflow-check.py      # سير العمل نفسه
python3 swift-api-check.py     # واجهات Swift + الأذكار + App Group
npm install jsdom && node jsdom-suite.mjs   # المحاكي
```

## بعد نجاح الترجمة

1. **كل تعديل جديد** ← `git add . && git commit -m "…" && git push` ← يبدأ الفحص تلقائيًا
2. عندما تصير الترجمة خضراء بثبات: أضف الأسرار الأربعة وابدأ مسار النشر (TestFlight)
3. على الساعة: جرّب النقرة المزدوجة، ثم **العدّ بحركة اليد** (☰ ← «العدّ بلا نظر» ← حركة) واضبط الحساسية
